# Guides

Concept guides that apply to more than one device. Each states which devices it was
verified on.

  Sahara/Firehose, entering and leaving EDL, loaders, crash dumps.

  A/B, slot attributes, fallback, the bootloader side.

  test slot, crash logs without a serial console, the bring-up order.
- [Boox firmware](boox-firmware.md): downloading, decrypting and inspecting update
  packages.
